# PRAHLAD BHAGAT JI
### Bartan • Kitchenware • Appliances

A production-ready, commercial retail showroom website for **PRAHLAD BHAGAT JI**, located on **Jhajjar Rd, Opposite Agarwal Metal Works, AERD Society, Rewari, Haryana**.

---

## 🏬 Features

- **Storefront & Showroom Gallery**: Real interior photography showing the central promenade, wooden coffered ceiling, stainless steel gondolas, and illuminated metalware niches.
- **Department Catalog**: Real-time search and filtering across Cookware & Bartan, Traditional Brass & Copper, Built-in Kitchen Appliances (KAFF Studio), Fine Dinnerware, Culinary Tools, and Storage.
- **Wedding Trousseau & Gifting Guide**: Authentic Indian traditions for bridal kitchen setups (*Vivah Bartan*) and housewarmings (*Griha Pravesh*).
- **Metal Care Compendium**: Authoritative, factual care and cleaning reference for Brass (*Pital*), Copper (*Tamba*), and Food-Grade Stainless Steel without pseudoscientific claims.
- **Interactive Google Map & Location**: Exact directions, visiting hours, and visitor inquiry desk.
- **Zero-Fake-Data Compliance**: Grounded 100% in verified business data and authentic physical photography.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (Stone Slate & Warm Amber Brass palette)
- **Icons**: Lucide React
- **Motion**: Framer Motion
- **Build**: Zero TypeScript errors, optimized production bundle (61 kB gzip)

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
